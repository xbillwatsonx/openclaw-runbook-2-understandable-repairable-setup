# Third-Party Notices - openclaw-runbook-2-understandable-repairable-setup

If the PUBLIC-MANIFEST allowlist contains third-party entries, list each one
here as a bullet at the start of a line. The first item must be the exact
allowlist path; `verify` cross-checks this list against the allowlist.

Example (indented so `verify` ignores it; real entries must start at column zero):

    - vendor/example.md Upstream License Name https://upstream.example/source

Projects with no third-party allowlist entries keep this file as-is.
